# DubLab

A student-facing ADR performance web app.

## Student use

1. Open DubLab in the current version of Chrome.
2. Pick a scene and role.
3. The first time a scene is opened, choose the matching class scene-pack `.tar.gz` supplied by the teacher.
4. Allow microphone access.
5. Record, review, scrub through playback, revisit saved takes in **Dubbed**, and export supported takes as MP4.

Scene packs are stored locally in the browser after import and are intentionally not included in this public repository.
